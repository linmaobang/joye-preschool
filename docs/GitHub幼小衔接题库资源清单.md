## 五、使用建议（结合「佳宜幼小衔接」）

1. **数学题扩充首选**：拉取 `shiyi-math-practice`，把 `src/data/questions.ts` 里的题按你的 `Question` 结构转换，可一次性增加约 400+ 道结构化题（20以内加减、比大小、人民币、找规律等），比你当前的题型覆盖面更广。
2. **拼音/识字扩充**：参考 `shiyi-grade-one-yuwen` 的拼音卡与生字卡数据结构；`StudyWord` 的 3000 字分级表可用于识字挑战。
3. **英语缺口提示**：GitHub 上"学前英语单词/句型题库"类资源相对稀少（多为英文 phonics 项目，面向母语儿童），如需英文题库可考虑自建单词表，或用 `FamilyEducation` 的英文字母描红作补充。
4. **许可注意**：`shiyi-math-practice` 与 `shiyi-grade-one-yuwen` 为 MIT，可直接引用；`FamilyEducation` 为 GPL-2.0（若整体引用需注意传染性）；其余多为开源但许可各不相同，导入前请确认 LICENSE。
