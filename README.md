# 佳宜幼小衔接（Joye Preschool）

专为 5-6 岁幼小衔接儿童设计的**游戏化综合启蒙 Web 应用**，涵盖**数学、拼音、识字、英语**四大学习模块，内置完整的成长激励系统——让孩子在"答题闯关、收集贴纸、升级称号"的挑战中爱上学习。

全端适配（手机 / 平板 / 电脑），数据保存在浏览器本地，无需注册登录，打开即用。

> 🌐 **在线体验**：https://joye-preschool.pages.dev

---

## 📚 学习模块

### 🔢 数学乐园
- **基础运算**：10 / 20 以内加减法、拆数游戏、相邻数、比大小、数列规律、生活应用
- **新题宝箱**：接入经典题库 **442 题**，覆盖 20 以内加减、100 以内数、大小比较、100 以内加减、人民币、找规律、观察物体、有趣的图形、解决问题等 10 类题型，看图题配 emoji 图形可视化

### ✍️ 识字乐园
- **3000 个常用汉字**，分简单（1200）/ 中等（1000）/ 困难（800）三档
- 两种题型："看字选音"（选正确拼音）与"看拼音选字"，交替出题
- 答对的字自动收入"已识"字库，支持语音朗读与组词联想

### 🔤 拼音天地
- 韵母 / 声母 / 整体认读 / 声调学习
- 两拼法、三拼法拼读动画（声母韵母"碰撞"合成音节）
- 拼音练习（拼音选字 / 字选拼音）、可交互拼音表、收藏夹

### 🇬🇧 英语启蒙
- 单词闪卡（200+ 单词）、常用句型、听音选词等练习

## 🛠️ 技术栈

- **前端**：React 18 + TypeScript + Vite
- **UI**：Mantine UI + Tailwind CSS
- **路由**：react-router-dom
- **数据存储**：浏览器 localStorage（无需后端）

## 🚀 本地运行

```bash
npm install          # 安装依赖
npm run dev          # 启动开发服务器（默认 5173，可用 -- --port 端口号）
npm run build        # 类型检查 + 构建产物到 dist/
npm run preview      # 本地预览构建产物
```

## ☁️ 部署到 Cloudflare Pages

```bash
npm run build
npx wrangler pages deploy dist --project-name=joye-preschool --branch=main
```

首次部署需先 `npx wrangler login` 登录 Cloudflare 账号。

## 💾 数据存储说明

- 所有学习进度、金币、贴纸、设置均保存在浏览器 `localStorage`（key：`joye_preschool_data`），无需账号与后端
- 请在「设置」页定期**导出备份**；不同设备间的数据相互独立
- 清除浏览器缓存前请先备份，避免进度丢失
